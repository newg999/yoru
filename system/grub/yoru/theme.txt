#  icono de cada sistema. La opción elegida, en blanco y resaltada; las
#  demás, en gris. Letra: Adwaita Sans (la consola, JetBrains Mono).

#  install.sh lo copia a /boot/grub2/themes/yoru/ junto con las fuentes
#  (*.pf2, hechas con grub2-mkfont). Si lo cambias:
#    sudo cp -r system/grub/yoru/* /boot/grub2/themes/yoru/
#    sudo grub2-mkconfig -o /boot/grub2/grub.cfg
# ============================================================================
