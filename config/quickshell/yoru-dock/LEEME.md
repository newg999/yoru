# yoru-dock

El estilo «Dock» de la barra de Yoru (Ajustes › Barra y dock › Dock).

Es un port de **LeyzS QsDock** (https://github.com/L3yzs/LeyzS-QsDock,
licencia MIT, © 2026 LeyzS: ver `LICENSE-LeyzS`), versión
49822e6 (22 oct 2026), adaptado a Yoru:

- Hyprland → niri (ventanas, pantalla completa, salir, área reservada).
- pywal → los colores de `yoru tema`.
- Textos en español.
- Las notificaciones las sirve Yoru (`comun/Notificaciones.qml`), que
  escribe la lista que lee el dock y atiende sus órdenes (`notifcenter`).

Lo arranca la barra de Yoru (`qs -c yoru-dock`) mientras el estilo es Dock.
